# Multi-Qubit State Visualiser for Teaching

## Project Overview

An interactive educational application for visualising quantum states and understanding fundamental quantum computing concepts.

## Features

- One, two and three-qubit state input
- Quantum amplitude calculations
- Measurement probability visualisation
- Dirac notation
- Bloch sphere representation
- Entanglement entropy analysis
- Interactive quantum concepts quiz

## Technologies Used

- Python
- Streamlit
- NumPy
- Plotly

## Installation

```bash
pip install -r requirements.txt
```

## Run Application

```bash
streamlit run app.py
```

## Project Domain

Quantum Computing – 25AM3504

## Objective

To make multi-qubit quantum states easier to understand through interactive visualisation.
